Conventions

  • Record id is a permanent kebab-case slug, unique inside its game and section.
  • verified is a boolean on every record. false means best-effort, not confirmed.
  • source is an optional URL or document name backing the record.
  • coverage is one of complete, partial, limited, official-only, empty.
  • Missing numbers are null, never 0 and never a guess.
  • Arrays are sorted deterministically; files contain no timestamps except the top-level generated field.
