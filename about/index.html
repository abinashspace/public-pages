About

How this site works

A deliberate choice: boring, static, complete, and readable by machines before humans.

Principles

  • No runtime dependency. No CDNs, fonts, analytics, or image hotlinking. The page you load is the repository.
  • HTML and JSON are generated from one source. Tables and JSON cannot disagree because both come from content/.
  • Stable identifiers. Slugs are permanent; data-* attributes and row ids mirror the JSON id.
  • Honest coverage. A section marked partial is a verified core, not a claim of completeness.
  • No JavaScript required. JS adds search and nothing else.

Accuracy

Every record has verified. true means the record was checked against the game or a documented source; false means it is best-effort and may contain errors. Where a field is genuinely unknown it is null — never a guess. GTA VI is official-only: nothing beyond confirmed Rockstar material is recorded.

Images

Most images are real in-game art — character portraits, vehicle and weapon renders, and box art — fetched from GTA Wiki by tools/fetch-images.mjs. That artwork remains the property of Rockstar Games / Take-Two Interactive and is used here for a personal, non-commercial reference site; see image credits.

Every remaining slot resolves to an original generated SVG placeholder at the exact target dimensions. To replace a placeholder with your own file, put it at the same path with the same basename and a real extension:

assets/img/portrait/gta-iii/claude.jpg
assets/img/vehicle/gta-v/adder.png
assets/img/weapon/gta-san-andreas/ak-47.webp

Rebuild: node tools/build.mjs. The build prefers the real file, updates data/images.json, and leaves every URL and record untouched. data/images.json lists every slot with its status (real or placeholder), so what is still missing is always explicit.

Build

node tools/validate.mjs   # data checks
node tools/build.mjs      # content/ + assets/ → docs/
node tools/serve.mjs      # local preview at http://localhost:8080

No npm install. Node 18+ only.
