Schemas

JSON Schema (draft 2020-12) per record type
PathRecordDescription
data/schema/characters.jsonCharactersNamed characters with role, affiliations and a short summary.
data/schema/missions.jsonMissionsStory and side missions in order, with giver, location and reward.

data/schema/weapons.jsonWeaponsWeapons by type with damage tier, ammo cap, price and unlock source.

data/schema/collectibles.jsonCollectiblesCollectible sets with totals and completion rewards.

Conventions

  • Record id is a permanent kebab-case slug, unique inside its game and section.
  • verified is a boolean on every record. false means best-effort, not confirmed.
  • source is an optional URL or document name backing the record.
  • coverage is one of complete, partial, limited, official-only, empty.
  • Missing numbers are null, never 0 and never a guess.
  • Arrays are sorted deterministically; files contain no timestamps except the top-level generated field.
